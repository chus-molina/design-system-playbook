## Cuándo usarlo

<UsageRule
  useWhen={[
    "Identificar visualmente al autor de un contenido (post, comentario, tarea)",
    "Mostrar los miembros asignados a un proyecto o tarea",
    "Header de la aplicación para indicar la sesión activa del usuario",
    "En listas o tablas donde la foto humaniza el contenido"

  avoidWhen={[
    "Cuando no hay usuario real asociado — no uses avatars como elementos decorativos genéricos",

    "En grupos de más de 5 sin contador — muestra máximo 4 y añade +N"

## Accesibilidad

- La imagen debe tener `alt` con el nombre completo del usuario.
- Si el avatar aparece junto al nombre escrito, usa `alt=""` para evitar repetición.
- Los indicadores de estado necesitan texto alternativo: usa `aria-label="Juan García — Online"`.
