## Importar

```tsx
import { Button } from '@/components/ui/Button'
```

## Uso básico

El botón más común es el **Primary** — úsalo para la acción principal de la pantalla. Solo debe existir uno por vista.

<Preview code={`<Button variant="primary">Guardar cambios</Button>`}>
  <Btn variant="primary">Guardar cambios</Btn>
</Preview>

## Variantes

Cada variante tiene un nivel de énfasis diferente. Elige según la importancia de la acción.

<Preview code={`<Button variant="primary">Primary</Button>
<Button variant="secondary">Secondary</Button>
<Button variant="outline">Outline</Button>
<Button variant="ghost">Ghost</Button>
<Button variant="destructive">Destructive</Button>`}>
  <Btn variant="primary">Primary</Btn>
  <Btn variant="secondary">Secondary</Btn>
  <Btn variant="outline">Outline</Btn>
  <Btn variant="ghost">Ghost</Btn>
  <Btn variant="destructive">Destructive</Btn>
</Preview>

<Callout type="tip" title="Jerarquía visual">
  En una misma pantalla, usa como máximo una acción Primary, una Secondary y una Ghost. Si tienes más de tres botones, algo falla en el flujo.
</Callout>

## Estados

### Disabled

Usa `disabled` cuando la acción no está disponible. Asegúrate de que el usuario entiende **por qué** está deshabilitado — añade un tooltip o un mensaje explicativo.

<Preview code={`<Button disabled>No disponible</Button>`}>
  <Btn disabled>No disponible</Btn>
</Preview>

### Loading

Usa `loading` mientras se procesa una acción asíncrona. El botón se deshabilita automáticamente.

<Preview code={`<Button loading>Guardando...</Button>`}>
  <Btn loading>Guardando...</Btn>
</Preview>

## Do / Don't

<DoDont description="El texto del botón debe describir exactamente la acción que ocurrirá.">
  <Do label="Usa verbo + objeto específico">
    <Btn variant="primary">Guardar cambios</Btn>
    <Btn variant="destructive">Eliminar cuenta</Btn>
  </Do>
  <Dont label="Evita textos vagos o genéricos">
    <Btn variant="primary">Click aquí</Btn>
    <Btn variant="destructive">Eliminar</Btn>
  </Dont>
</DoDont>

<DoDont description="No sobrecargues una misma área con múltiples botones del mismo peso visual.">
  <Do label="Un Primary, el resto de menor énfasis">
    <Btn variant="primary">Confirmar pedido</Btn>
    <Btn variant="outline">Cancelar</Btn>
  </Do>
  <Dont label="Dos botones Primary compiten entre sí">
    <Btn variant="primary">Confirmar</Btn>
    <Btn variant="primary">Cancelar</Btn>
  </Dont>
</DoDont>

## Accesibilidad

- El botón tiene rol `button` nativo — no uses `div` o `span` como botón.
- En estado `disabled`, el botón no es focusable. Si necesitas mantener el foco, usa `aria-disabled` en su lugar.
- Los botones de solo icono deben llevar `aria-label` descriptivo.
- El estado `loading` debe comunicarse con `aria-busy="true"` y un texto para lectores de pantalla.

<Callout type="warning" title="Botones solo con icono">
  Si el botón no tiene texto visible, añade siempre `aria-label`. Sin él, los usuarios de lectores de pantalla no saben qué hace el botón.
</Callout>
