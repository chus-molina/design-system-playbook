## Cuándo usarlo

<UsageRule
  useWhen={[
    "Botones o iconos sin texto visible — el tooltip es su label de accesibilidad",
    "Abreviaturas o términos técnicos que necesitan explicación",
    "Acciones cuyo efecto no es evidente por el contexto visual",
    "Información secundaria que no justifica espacio permanente en la UI"
  ]}
  avoidWhen={[
    "Para información crítica que el usuario necesita leer para tomar una decisión",
    "En dispositivos táctiles como única forma de revelar información (no hay hover en touch)",
    "Para textos largos — el tooltip está diseñado para etiquetas cortas (máx. 5 palabras)",
    "Cuando el elemento ya tiene un label visible claro — añadir tooltip repite información"
  ]}
/>

<Callout type="warning" title="No es un sustituto del label">
  Si el usuario necesita leer el tooltip para entender qué hace un botón, el problema es el diseño, no la falta de tooltip. Revisa si el botón necesita texto visible.
</Callout>

## Accesibilidad

- El tooltip se asocia al elemento con `role="tooltip"` y `aria-describedby`.
- Los iconos sin texto visible deben tener `aria-label` además del tooltip visual.
- El tooltip no debe ser la única forma de comunicar información en dispositivos táctiles.
- El delay de 300ms evita activaciones accidentales al mover el cursor.
