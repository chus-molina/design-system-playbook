## Tipos de modal

### Confirmación destructiva

Para acciones irreversibles. El título es siempre una pregunta directa.

<Callout type="danger" title="Solo para acciones irreversibles">
  El modal de confirmación tiene un coste de fricción alto — interrumpe el flujo del usuario. Úsalo únicamente cuando la acción no se pueda deshacer.
</Callout>

### Formulario en contexto

Captura datos sin abandonar la página actual. El usuario mantiene el contexto de dónde estaba.

### Información / Detalle

Muestra información adicional de un elemento sin necesitar una navegación nueva.

## Cuándo usarlo

<UsageRule
  useWhen={[
    "La acción es irreversible y necesita confirmación explícita (eliminar, cancelar suscripción)",

    "Mostrar el detalle de un ítem en una tabla sin perder el contexto",

  avoidWhen={[
    "Para confirmaciones de acciones reversibles — usa un toast o inline feedback",

    "Información que el usuario necesita consultar con frecuencia — ponla visible en la UI",
    "Apilar modales uno sobre otro — nunca abras un modal desde otro modal"
  ]}

## Accesibilidad

- El modal debe tener `role="dialog"` y `aria-modal="true"`.
- El foco debe quedar atrapado dentro del modal mientras está abierto.
- Al cerrarse, el foco vuelve al elemento que abrió el modal.
- La tecla `Escape` siempre cierra el modal.
- El título es el `aria-labelledby` del diálogo.
